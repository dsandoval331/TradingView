# Reverse Engineering Sector Daily Winners

The main 11-sector tracker includes a calculated historical review section. Top 1 (default), Top 2 and Top 3 are configurable. Rank by unrounded close-to-close daily return within the complete 11-sector universe. Require return ≥0.05%, matching green daily heatmap shading. Never fill extra slots with red, flat or neutral sectors. Exact ties use ticker ordering to cap selections at N; displayed competition ranks may tie. Incomplete comparisons produce an explicit unavailable day.

History uses the existing published split-adjusted bars and SPY session calendar. All currently loaded history initializes indicators, averages and streaks; the heatmap date/Sessions filter chooses displayed dates and summary populations. All available exposes the full loaded history. No new source, collection job, database table or immutable snapshot recording is introduced. Current-data revisions can restate history. Only the main sector tracker shows this section; stock and synthetic Tech/AI universes are not mislabeled sectors.

Before-session characteristics use the prior session only: volume ratio, daily return, relative-to-SPY return, rank/change, RSI14/difference, Mansfield200, 5/20-session returns, EMA20/50 position and all six streak counters. Previous opening gap is previous open / its preceding close − 1. Winning-day gap uses current open / prior close − 1. Both are shown in percent. Winning-day volume ratio, returns, ranks, indicators, close-range position and ending streaks are separately labeled observations of the winning day. Day of week is the market session date, formatted in UTC to preserve that date.

Volume SMA includes the measured session and follows Sessions (20, 60, 120 or All); missing/nonfinite/negative values reset the window, zero is valid, zero mean has no ratio. EMAs are existing SMA-seeded implementations. The directional daily average uses 60 valid prior returns excluding today and at least five positives. Range position is (close − low)/(high − low), requiring valid ordered positive range enclosing close. Unavailable values remain N/A.

Streaks follow existing Event Log rules for daily, relative, rank, rank change, RSI difference and Mansfield. Positive/negative signs define green/red, rank uses better/worse than midpoint 6; flat/missing values reset both. These sign streaks differ from heatmap neutral shading and are explicitly labeled. History begins observed runs rather than asserting a true onset before data availability.

Characteristic-frequency comparison shows true/available denominators for selected winners and all other nonselected sectors on the same complete dates. Missing values are excluded. Before-session and during-session characteristics remain distinct. This is descriptive exploration, not a validated signal, correlation estimate or causal/predictive result; selecting winners by return necessarily affects same-day associations. Sector/date observations overlap.

Winner CSV exports one row per selected winner with date, weekday, raw metrics, gaps, volume ratios, EMA values and all prior/ending streak counters, following current Top N and visible dates. Newest five dates are open initially; other dates remain independently expandable. A symbol button selects that sector/date in the existing detail and chart panels.

## Compact common-characteristic summary

The top of the section displays at most three positive conditions for Before session and three for During session, ranked by count of matching selected winner observations. Ties sort by available-observation frequency and then stable feature key. Coverage and yes/available denominators are explicit, preventing a rare fully observed condition from displacing a more commonly observed one. Candidate conditions are the existing documented characteristic-frequency conditions; the summary does not search all possible value intervals or optimize thresholds.

Numeric typical values are medians among winners where the condition is true: relative volume multiples, daily return percent, relative-return pp, longest prior green run among the six measures, opening gap percent, daily return / prior positive average, and close position percent. EMA conditions display Above EMA20/50. These are descriptive typical values, not exact modes or recommended entry thresholds. Other-sector percentages remain alongside highlighted conditions. The most represented weekday includes ties and counts winner observations; it is not a weekday win rate. Top N, dates and Sessions recompute the summary. All daily metric details are now closed by default and remain expandable; frequency tables and CSV are retained.
